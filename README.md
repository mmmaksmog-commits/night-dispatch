# 🚕 Ночной диспетчер

**Ночная смена диспетчера такси: распределяйте машины по вызовам и объезжайте пробки.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/night-dispatch/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Карта города на Canvas с живыми окнами
- Маршруты по алгоритму Дейкстры с учётом пробок
- Терпение клиентов, чаевые за скорость, рейтинг
- Пик вызовов ночью и четвёртая машина в час ночи
- Подстраивается под портретный и альбомный экран

## Стек

JavaScript, Canvas. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/night-dispatch.git
cd night-dispatch
python3 -m http.server 8000
```
